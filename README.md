# Chemistry Hub – Determining Rate Laws

Static single-page site by Mr. Hesham. The whole site is `index.html`, with no build step.

To view it locally, open `index.html` in a browser.

Deployed on Vercel; every push to `main` deploys automatically.

Live sync uses Supabase. On a new Supabase project, run `supabase.sql` once in the SQL Editor.
